# Issue tracker

Issues live in GitHub Issues on `FAIR-DM/shared`, managed through the `gh` CLI.

- One issue per problem or proposal. A change to what a reusable workflow does gets an issue first,
  so its effect on portals is stated before the work starts.
- An issue that changes a reusable workflow names what a portal sees change: a check name, a
  secret, something the portal must provide, or the platform it runs on.
- Dependabot pull requests are not issues. They merge through the auto-merge workflow once the
  example portal passes.
