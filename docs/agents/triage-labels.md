# Triage labels

The label roles and the strings this repository uses, kept in step with GitHub:

| Role | Label | Meaning |
|---|---|---|
| needs-triage | `needs-triage` | New and unreviewed. Nobody acts on it yet |
| needs-info | `needs-info` | Waiting on an answer from the reporter |
| ready-for-agent | `ready-for-agent` | Triaged and safe for automated work to pick up |
| ready-for-human | `ready-for-human` | Triaged, and needs a person's decision or review first |
| wontfix | `wontfix` | Decided against. Stays closed with the reason |

These are added to GitHub's default labels. Automation routes issues by these five.
